# Docs site

The STITCH++ documentation, built with [Starlight](https://starlight.astro.build/).

```sh
npm install
npm run dev      # http://localhost:4321/STITCHplusplus/
npm run build    # static site in dist/
```

- `src/content/docs/guide/`: the guide for humans, with the key-value store tutorial.
- `agents/`: the guide for agents, plain Markdown served at `/agents/<name>.md` (`src/pages/agents/`).
  `overview.md` is the entry point. The language files, `reproducers.md` and `cli.md` are copied
  from `skill/stitch/reference/` and `docs/cli.md` (`src/agent-guide.ts`).
- `src/content/docs/reference/` is generated by `scripts/sync-reference.mjs` from
  `skill/stitch/reference/*.md` and `docs/cli.md`. Edit those files instead.

The tutorial's code is shown per language with `<Lang id="...">` blocks
(`src/components/Lang.astro`). Pages with `languages: true` in their frontmatter show the language
picker under the title. The finished tutorial harnesses are in `examples/<lang>-demo/`.

Command output in the tutorial comes from running it in each language, and is stored in
`src/tutorial-output/<lang>/<name>.txt`. `<RunOutput name="...">` shows the picked language's file.
When the CLI's output changes, run the tutorial again and replace those files.

`.github/workflows/docs.yml` publishes the site to GitHub Pages on pushes to `main`.
