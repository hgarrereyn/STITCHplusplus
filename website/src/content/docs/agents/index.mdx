STITCH++ fuzzes a library through its API. You write **stubs**, small functions that each make one
API call. The fuzzer chains them into **programs**, generates the arguments, and reports crashes,
undeclared exceptions and failed checks. Everything builds and runs in Docker.

## Setup

Requires Docker with buildx and Python 3.9 or newer.

```sh
pip install stitch-fuzz
stitch setup --lang <lang>    # cpp, objc, python, javascript, java, go, rust, ruby, swift
stitch skill                  # optional: installs the STITCH++ skill in ./.claude/skills
```

Offline, `stitch guide` prints the workflow guide and `stitch guide <lang>` the syntax for one
language. This section is also available as one markdown file: [`llms.txt`](/STITCHplusplus/llms.txt).

## Read in this order

1. [Workflow](/STITCHplusplus/agents/workflow/): the steps, and when each one is done.
2. Your language page: `stitch guide <lang>`, or [Reference › Languages](/STITCHplusplus/reference/languages/cpp/). Read it before writing stubs.
3. [Writing stubs](/STITCHplusplus/agents/stubs/): rules that make stubs effective.
4. [Reading the probe report](/STITCHplusplus/agents/probe/): what each line means and what to change.
5. [Triage](/STITCHplusplus/agents/triage/): deciding whether a crash is a harness bug or a library bug.

## Terms

| Term | Meaning |
|---|---|
| stub | a function that makes one API call. Its signature declares its inputs and outputs |
| object | a value one stub produces and later stubs use (a parsed document, a handle) |
| borrow / take / new | a stub uses an object / consumes it / produces one |
| fuzzed parameter | any parameter that is not an object. The fuzzer picks its value |
| program | a sequence of stub calls; object inputs refer to earlier outputs |
| bail | an expected failure (invalid input, unmet precondition). Not a bug |
| bug | a crash, sanitizer report, undeclared exception, failed `check`, or timeout |
| check | `check(cond, "what")`: a property that must hold. False is a bug |
| data type | a tag on a string or bytes parameter that adds seeds, a dictionary or a decoder |
| attribute | state the harness stores on an object, for facts the library cannot report |
| campaign | one fuzzing run (`probe`, `main`, or a `--name`). Crash ids are per campaign |

## Rules that always apply

- Pass `--json` when you parse a command's output.
- Run commands from inside the project, or pass `-C <dir>`.
- Do not report a library bug until [triage](/STITCHplusplus/agents/triage/) says it is one.
- Keep stubs compiling across library versions, so `--rev` and `bisect` work.
