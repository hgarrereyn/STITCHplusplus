---
title: Install
description: Install the stitch command and a language image.
---

Install the command:

```sh
pip install stitch-fuzz
```

Then get the image for each language you want to fuzz:

```sh
stitch setup --lang python          # or cpp, objc, javascript, java, go, rust, ruby, swift
stitch setup --lang python,go       # several at once
stitch setup --lang all
```

`stitch setup` checks that Docker works, then pulls the prebuilt image for your version of
`stitch-fuzz`. If there is none, it builds the image locally.

## Versions

Each version of `stitch-fuzz` uses exactly one set of images, tagged by a hash of their sources
(never `latest`). Upgrading the command is the only thing that changes the images. To keep results
reproducible, pin the version:

```sh
pip install stitch-fuzz==X.Y.Z   # the version you set up with
stitch --version
```

Reproducers from `stitch repro` record the version they were made with and pin their toolchain
image by digest, so they keep working after you upgrade. Each
[release](https://github.com/hgarrereyn/STITCHplusplus/releases) lists its images and their
digests.

## Use it with a coding agent

STITCH++ ships a guide for coding agents as a skill:

```sh
stitch skill            # into ./.claude/skills
stitch skill --user     # into ~/.claude/skills
```

Agents without skills can read `stitch guide`, or the agent guide on this site: plain Markdown files
that start at [`agents/overview.md`](/STITCHplusplus/agents/overview.md).

## From a checkout

```sh
git clone https://github.com/hgarrereyn/STITCHplusplus
cd STITCHplusplus
pip install -e .        # or run bin/stitch directly
```
