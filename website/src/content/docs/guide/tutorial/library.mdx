This tutorial fuzzes a small key-value store. The store has the same API in every language. Pick
your language above; the choice applies to every page of the tutorial.

The store can:

- create an empty store
- `put` a key and a value (keys and values are single lines, keys are not empty)
- `get` and `remove` a key
- `dump` the store as text, one `key=value` line per entry
- `load` that text back into a store

It also has a few planted bugs. You don't need to know where they are: finding them is the
fuzzer's job.

## The API

<Lang id="python">
```python
import kvlib

st = kvlib.Store()
st.put("a", "1")             # ValueError for an empty key or a newline
st.get("a")                  # "1"
st.remove("a")
text = st.dump()             # "a=1\nb=2"
st = kvlib.load(text)        # ValueError for a line without '='
```

Source: [`examples/python-demo/lib/kvlib/__init__.py`](https://github.com/hgarrereyn/STITCHplusplus/blob/main/examples/python-demo/lib/kvlib/__init__.py)
</Lang>

<Lang id="objc">
```objc

[st removeKey:@"a"];
```

## Get the code

```sh
git clone https://github.com/hgarrereyn/STITCHplusplus
cd STITCHplusplus/examples
```

Each language has a folder `examples/<language>-demo/`. Its `lib/` folder holds the store, and its
`harness/` folder holds the finished harness. This tutorial writes the harness again from scratch
in a new project, so you can compare your result with the finished one.
