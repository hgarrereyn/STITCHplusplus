## Build

<RunOutput name="build" />

`stitch build` compiles the harness against the library image and prints compile errors with file
and line. `stitch check` runs static checks: stubs that can never run because nothing produces
their inputs, attributes that are read but never set, and data types with nothing to start from.

## Probe

A probe is a short run with one worker, followed by a report on the stubs that are not working.

<RunOutput name="probe-1" />

The first line is the summary:

- **execs**: programs run, and how many per second.
- **edges**: branches of the library reached so far.
- **calls bailing**: the share of calls rejected as invalid input. That work is wasted.
- **crash/timeout programs saved**: programs that found a bug. If there are some already, leave
  them for page 6.

The lines below the summary name stubs to look at, such as stubs that never succeed or that are
often skipped because their input object is missing.

much of it and reads few entries from the rest. The next page fixes this with a data type, and adds
a check.
