You write **stubs**: small typed functions that each make one API call. STITCH++ **stitches** them
into programs, passes objects from one call to the next, and fuzzes the arguments. It keeps the
programs that reach new code and reports crashes, uncaught exceptions and failed checks.

```python
@stitch.endpoint(bails_on=(ValueError,))
def load(text: Str[256, KvText]) -> New[Store]:
    return kvlib.load(text)

@stitch.endpoint
def roundtrip(st: Borrow[Store]):
    again = kvlib.load(st.dump())
    stitch.check(dict(again.items()) == dict(st.items()), "dump/load roundtrip")
```
